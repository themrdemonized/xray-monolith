# R1 PDA Map API v1

Форк добавляет в Modded Exes Lua-модуль `pda_map`: общий API рисования и ввода на карте КПК для разных аддонов. Инструменты, кнопки, цвета, ластик, отмена и формат сохранения остаются в аддонах. R1 Map Pencil 0.4.0 использован как справочный пример; его DLL, интерфейс, атлас иконок и двоичный формат сохранения в движок не включены.

База исходников: обычные Modded Exes `2026.10.11`, commit `c57fe5b9fab4fe0506659db03137c52d2500eb2f`; MT — `871e2491228a64f0d5e257c7a7e0255feb841ac8`. Реализация находится в исходниках движка и экспортируется в Lua. Адресов конкретного EXE, FFI и отдельной DLL-перехватчика нет. Старый EXE не получает API от установки скриптов. Проверка в аддоне: `pda_map and pda_map.version() == 1`.

## Координаты и отрисовка

- `"global_map"` — координаты общего полотна карты: X вправо, Y вниз, без внутренней поправки X на пропорции экрана. Это координаты изображения, а не метры игрового мира.
- Имя локации из `level_maps_single` — мировые X/Z в метрах. Второй аргумент координат означает Z. Такие рисунки следуют за локацией при изменении её расположения на общей карте.
- `screen` — виртуальные координаты UI движка, обычно 1024 x 768, которыми пользуется курсор КПК. Это не пиксели рабочего стола.
- Преобразование использует текущую позицию и масштаб карты, включая плавное движение, и учитывает пропорции UI. Поворот отдельных окон карты не поддерживается; штатные карты КПК этот режим не используют.
- Рисунки выводятся после карты и её меток, перед рамками, навигацией и контекстным меню. Геометрия обрезается по области карты, включая путь вершин 3D КПК. Линии объединяются в пакеты треугольников; текстуры кэшируются по слоям. Видимый результат и производительность требуют проверки в игре.

## Lua API

`token` — ненулевой ID слоя; `id` — ненулевой ID команды. Ошибка возвращает `0` для ID либо `false` для операций с логическим результатом.

| Функция | Результат / назначение |
|---|---|
| `version()` / `ready()` | Версия API (`1`) / наличие инициализированной карты |
| `viewport()` | Таблица `ready`; при готовности также `shown`, `x`, `y`, `width`, `height`, `zoom` |
| `register_layer(owner)` | Создать слой с уникальным именем аддона/слоя, до 128 байт; дубликат отклоняется |
| `valid_layer(token)` | Проверить существование слоя в текущем UI |
| `clear_layer(token)` / `release_layer(token)` | Очистить содержимое / удалить слой и освободить его ввод |
| `set_visible(token, bool)` / `count(token)` | Показать или скрыть слой / число команд; скрытие освобождает ввод |
| `remove(token, id)` | Удалить одну команду этого слоя |
| `add_line(token, map_name, x1, y1, x2, y2, width, color)` | Линия; совпадающие точки дают квадратную точку |
| `add_polyline(token, map_name, points, width, color, closed)` | Ломаная из непрерывного массива `{{x,y}, {x,y}, ...}` |
| `add_marker(token, map_name, texture, x, y, width, height, color, scale_with_map)` | Текстурный прямоугольник с центром в заданной точке |
| `to_screen(map_name, x, y)` | `ok, screen_x, screen_y` |
| `from_screen(map_name, screen_x, screen_y)` | `ok, map_x, map_y` |
| `acquire_input(token)` / `release_input(token)` | Занять ввод карты / освободить собственный ввод |

Все функции вызываются через `pda_map.`. Толщина линий задаётся в единицах UI и остаётся постоянной при масштабировании; стыки и концы сегментов плоские. Размер маркера при `scale_with_map=false` задаётся в единицах UI, при `true` — в координатах карты с преобразованием масштаба и пропорций UI. Текстура — зарегистрированный UI ID, включая участок атласа, либо существующий DDS-путь без `.dds`. Ресурсы предоставляет аддон. Цвет — беззнаковый ARGB, например `0xffffffff`.

Ограничения: 32 слоя, 4096 команд на слой, 65536 точек суммарно, 4096 точек на ломаную, 128 разных кэшированных текстур на слой, включая белый прямоугольник линий. Толщина >0 и <=128; размеры маркера >0 и <=2048; конечные координаты в пределах +/-10000000. Открытая ломаная требует минимум две точки, замкнутая — три. Неверный ID, неизвестная карта, отсутствующая текстура, некорректные данные и превышение лимита отклоняются без частичного добавления команды.

## События

Вместе со сборкой установите обновлённый `callbacks_gameobject.script` из форка. Новые события:

```lua
RegisterScriptCallback("on_pda_map_visibility", function(shown) ... end)
RegisterScriptCallback("on_pda_map_input", function(event) ... end)
```

Событие видимости приходит после показа/скрытия карты. Ввод получает только выбранный слой, когда курсор находится в доступной области карты. Навигационные кнопки, заблокированная карта и открытое контекстное меню сохраняют штатный ввод. `acquire_input` выбирает инструмент карты; он не захватывает мышь Windows и не гарантирует события за пределами области карты.

Таблица события: `owner`, `layer`, `action`, `dik` (`-1` для мыши), `screen_x`, `screen_y`, `shift`, `ctrl`, `alt`, `left_held`, `consume=false`. При успешном преобразовании добавляются `global_x`, `global_y`; над локацией — `level_name`, `world_x`, `world_z`. Локация определяется по текущим прямоугольникам карты. Высота мира и вершины графов не вычисляются.

Действия: `left_down`, `left_up`, `left_double_click`, `right_down`, `right_up`, `middle_down`, `middle_up`, `mouse_move`, `wheel_up`, `wheel_down`, `key_down`, `key_up`. Для обработанного действия установите `event.consume=true`; иначе движок продолжит штатную обработку. Проверяйте свой `event.layer` и не сбрасывайте решение другого обработчика. Во время Lua-вызова блокировка слоёв отпущена: обработчик может добавлять, удалять и освобождать свой слой.

## Сохранение и жизненный цикл

Закрытие карты освобождает ввод, сохраняя рисунки до сброса или уничтожения UI. При открытии инструмента заново занимайте ввод. Сброс и уничтожение карты удаляют все слои и ресурсы. ID слоя не переиспользуется в течение процесса; после загрузки сохранения и пересоздания UI проверяйте `valid_layer()` и создавайте слой заново. ID команд также временные.

Движок не сохраняет рисунки, не изменяет формат сейва и не переносит старые DLL-данные. Аддон сохраняет координаты и стили в собственном версионированном состоянии и восстанавливает слой после загрузки. Нативные ID и координаты UI в сейв не записывайте. При закрытии, смерти, удалении актёра и переходе отключайте инструмент согласно логике аддона. Если отпускание мыши случилось вне карты, состояние `left_held` позволяет остановить незавершённый штрих.

Пример: [R1_Pda_Map_Example.lua](../examples/R1_Pda_Map_Example.lua). Он находится вне `gamedata/scripts` и самостоятельно не включает карандаш. Существующему R1 Map Pencil нужна отдельная адаптация; этот форк не заставляет его старую DLL пользоваться новым API.

Сборка — штатная `src/engine-vs2022.sln` в VS2022 с сохранением лицензии и авторства upstream. Полный справочник: [EN](R1_PDA_Map_API_EN.md).

PR находится в черновике. Проверки и их границы указаны в описании PR и относятся только к указанной ревизии. Эта правка исходников не является выпуском бинарного релиза.

Приёмка в игре: два независимых слоя; рисование поверх меток, движение и масштабирование; обрезка у краёв карты в 2D/3D КПК; навигация, колесо и меню; закрытие/повторное открытие, смерть, загрузка и переход; отказ второму владельцу ввода; лимиты и некорректные данные. Обычные и MT-сборки, рендереры и необходимые настройки проверяются отдельно.
