# API карты КПК для Lua-аддонов

Движок предоставляет область карты и её текущую геометрию. Рисунки, слои, инструменты и сохранение принадлежат Lua-аддону. Используются существующие CUIScriptWnd, CUIStatic:SetLineTo, текстуры и обрезка UI.

- `pda_map.version()` — 2.
- `pda_map.window()` — текущий CUIWindow области карты или nil до создания. Дочерние окна рисуются поверх карты, под окружающими кнопками и контекстным меню.
- `pda_map.info("global_map" или имя уровня)` — `{ready=false}` для недоступной/повёрнутой карты. Иначе: ready, global, shown, locked, x, y, width, height, bound_x1/y1/x2/y2, zoom, aspect. Геометрия обновляется при движении карты. Bounds — штатный BoundRect с поправкой на аспект.
- `CUIWindow:GetParent()` и `IsChild(window)` — проверка присоединения и отсоединение Lua-окон.
- `on_pda_map_update` вызывается после обновления движения/навигации карты. Обновляйте Lua-окна здесь; Lua не вызывается из отрисовки с параллельным GC.

Формулы приведены в [EN](R1_PDA_Map_API_EN.md). Глобальные координаты относятся к изображению карты без UI-аспекта; координаты уровня — мировые X/Z. Для дочернего окна вычитайте абсолютное начало Lua-слоя. Учитывайте поправку штатного отрисовщика при повороте UI-линий.

Lua владеет своими окнами: SetAutoDelete(false) + AttachChildKeepOwner с сохранением Lua-ссылок. При отсоединении берите текущий GetParent(), не старый указатель движка. После загрузки создавайте UI заново. При закрытии, смерти и переходах прекращайте инструмент/захват мыши. Сохраняйте только версионированные Lua-координаты и стиль.

Командный API v1 предыдущего черновика заменён API v2. Отдельный пример R1 Map Pencil Lua показывает рисование и хранение в аддоне. Старую DLL нужно адаптировать отдельно; PR сам не включает карандаш.

Сборка — штатная VS2022 solution с лицензией и credits upstream. Проверки относятся к ревизии и сценариям в описании PR.
