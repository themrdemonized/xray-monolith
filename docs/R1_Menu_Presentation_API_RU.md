# R1 Menu Presentation API (экспериментальный)

База: обычные Modded Exes 2026.10.11. Четыре функции в `level`:

```lua
token = level.menu_scene_begin(update_level) -- false: пауза; true: живой уровень
ok = level.menu_scene_set_camera(token, position, direction, up, fov_degrees)
active = level.menu_scene_active(token)
ok = level.menu_scene_end(token)
```

Вызывать из `Update` UI главного меню после активации и подготовки уровня. Без готового одиночного уровня `begin` возвращает 0. API сам не загружает сцену и не открывает меню. Повторный захват отклоняется; камера и завершение требуют полученный ненулевой token. Направление и верх — векторы, а не углы HPB. Нулевые, параллельные, нечисловые векторы и FOV вне (1,179) отклоняются.

Вызовы принимаются на потоке меню. Запрошенная камера применяется после UI `Update` в callback кадра меню; чтение камеры внутри `Update` ещё может возвращать камеру актёра, рассчитанную раньше в этом кадре. Проверять итоговую позу нужно в отрисованном кадре. Пример предполагает прозрачный UI главного меню от подключающего аддона.

Мир рисуется под обычным меню. Пауза использует существующую остановку таймеров и снятый callback уровня. UI и траектория камеры считают время через уже имеющийся `device():time_continual()`. Живой режим запускает таймер и снятый callback уровня один раз за кадр меню. Штатная пауза игровых звуков сохраняется. Сохранение живой презентационной сцены запрещается до отправки пакета.

Закрытие меню, перезагрузка UI, выгрузка уровня и уничтожение меню освобождают режим. Камера, проекция, пауза и второй viewport восстанавливаются. В сейвы состояние API не записывается. Пока API не захвачен, обычное меню сохраняет своё поведение.

Локации, NPC, анимации, облёты, проверка препятствий, ввод, HUD/тело героя, интерфейс и случайный выбор остаются в Lua. В API нет сцен R1, адресов EXE, DLL-хуков или нового таймера. Независимый Lua-код способен менять мир во время паузы; визуальные и звуковые эффекты требуют проверки конкретного сценария. MT и другие рендереры требуют отдельной адаптации и проверки.

`examples/R1_Menu_Presentation_Demo/gamedata/scripts/R1_menu_presentation_demo.script` показывает облёт на паузе средствами Lua. Нужны загруженный уровень и этот EXE. Это небольшой пример, полный R1 3D Menu и перенос его DLL-backend сюда не включены.

Проверенный тестовый аддон из двух файлов: `examples/R1_Menu_API_Test`, инструкции RU/EN внутри. Создание NPC и проверочный runner остаются вне устанавливаемого аддона.
