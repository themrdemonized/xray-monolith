# R1 XREAL Native 0.1.1 — экспериментальный MT DX11

Геометрическое стерео SBS для точной сентябрьской MT DX11. Отдельная DLL; EXE на диске не заменяется. Это пробник мира и обычного прицеливания, а не завершённая VR-адаптация.

## Установка

1. Установить этот ZIP через «Установить мод из архива» в MO2 и включить мод. Корень архива содержит gamedata. Альтернатива без MO2: скопировать gamedata в корень отдельной тестовой игры.
2. Запускать **AnomalyDX11.exe из MT 12.09.2026**, SHA256 `C43701F5822950172C9D13A9CD4C92CBDA3E94060CAE794FBA81DEDFD5BA43D0`. Обычная не-MT, AVX и другие сборки этим пакетом не поддерживаются. Подмена имени EXE не поможет.
3. Убрать предыдущий тестовый загрузчик R1_live/modxml_r1_stereo_test, если вручную устанавливали его. Выключить ReShade SuperDepth3D и другие стереоконвертеры, а также старый R1 XREAL Probe с той же F10.
4. Перевести очки в SBS и выбрать на них 3840x1080. Для пробника нужен фактический широкий backbuffer с отношением сторон 3..4. Обычный 1920x1080 даст отказ -24.
5. Отключить HDR и MSAA, в консоли игры выполнить `ssfx_taa (0,0,0,0)`. При необходимости перезапустить игру для применения графических настроек. Аддон сам настройки не переписывает.
6. Загрузить сохранение. Нажать **F10**, чтобы включить стерео. Повторная F10 или Esc выключает его. Открытие инвентаря/КПК, смена настроек, загрузка и переход выключают режим; включать повторно вручную.

MCM необязателен. При его наличии раздел **R1 XREAL Native** позволяет переназначить клавишу, расстояние между глазами (по умолчанию 64 мм) и дистанцию сведения (2 м). Изменения выключают стерео и действуют после следующего включения. После запуска и загрузки режим по умолчанию выключен.

## Ограничения

- Финальная компоновка скрывает 2D HUD. Меню, инвентарь и КПК не адаптированы под SBS: для работы с ними выключить пробник и при необходимости вернуть очки в 2D. Этот пакет предназначен для короткой проверки мира и оружия.
- Правый глаз использует исходную игровую камеру. У левого есть отдельный геометрический вид. Точная калибровка попаданий и весь набор оружия не проверены.
- Нет трекинга головы/Phoenix UDP, поддержки 3DSS/SecondViewport и оптических прицелов. Нет отдельных историй SSR/AO; возможны артефакты. Не включать одновременно сторонние hooks этих функций.
- Приостановка обновлений дольше 1.5 с прекращает стереорендер. Долгая игра, все переходы и полный состав GAMMA не сертифицированы.

## Диагностика и удаление

Лог: appdata/R1_XREAL_Native.log и строки `[R1_XREAL_NATIVE]` в xray-логе. -10: другая EXE или конфликт перехвата; -20: HDR/MSAA/SecondViewport; -25: TAA включён; -24: узкое разрешение; -21/-23: графические ресурсы/компоновка. Исправить настройку и повторить F10; после ошибки загрузки DLL перезапустить игру.

Удаление: выключить мод в MO2 и перезапустить игру. При ручной установке удалить только файлы из этого архива. Новая игра не требуется; собственных данных аддона в сохранении нет. DLL остаётся загруженной до завершения процесса, даже когда стерео выключено.
