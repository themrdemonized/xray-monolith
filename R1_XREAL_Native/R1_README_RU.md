# R1 XREAL Native — эксперимент для разработчиков

Состояние на 29 сентября 2026: отдельная x64 DLL повторно отрисовывает геометрию мира с двух позиций в одном игровом кадре и собирает изображение side-by-side (слева левый глаз). Это не конвертация готовой картинки через depth buffer. Файл EXE на диске не меняется; MinHook изменяет три участка кода в памяти процесса. Полноценный игровой релиз пока не готов.

## Что уже проверено

- В изолированной копии сентябрьской MT DX11 выполнены 1172 пары / 2344 прохода; второй запуск с пистолетом — 1139 пар / 2278 проходов на момент контрольного отсчёта. Это счётчики, не измерение FPS.
- Захвачена SBS-картинка мира и прицеливания `wpn_fort`: справа вид вдоль прицела, слева вид сбоку. В тесте `IsZoomed()` вернул true, после выстрела боезапас изменился с 12 на 11. Точность точки попадания этим не доказана.
- Отключение и снятие перехватов завершились нормально. Игра использовала отдельные appdata, настройки и копию сохранения.
- Математические тесты и настоящий D3D11 WARP-тест компоновки прошли. Математический тест проверяет эталонный расчёт, а не все реальные матрицы движка.

## Что пока не поддержано

2D HUD перекрывается финальной компоновкой. Меню не адаптированы под SBS. Нет готового пользовательского загрузчика, MCM и объединения с Phoenix/head tracking. Не проверены точность попаданий, оптические прицелы, переходы, перезагрузка сохранения и продолжительная игра. HDR, MSAA и активный SecondViewport отвергаются кодом. TAA должен быть выключен вручную: автоматического запрета в DLL пока нет. Раздельные истории SSR/AO/других эффектов ещё не реализованы. Профиль AVX есть, но живого запуска AVX в этом наборе доказательств нет. Совместимость с GAMMA не заявляется.

Не устанавливайте тестовые `R1_live.script` и `modxml_r1_stereo_test.script` в рабочий профиль: они управляют тестовым персонажем, нажимают прицеливание/огонь и закрывают игру.

## Файлы и начало работы

1. Прочитать [руководство разработчика](R1_DEVELOPER_RU.md).
2. Собрать из x64 Native Tools Command Prompt for VS 2022: `R1_build.cmd`.
3. Выполнить `R1_test_math.cmd` и `R1_test_gpu.cmd`.
4. Для запуска нужен свой Anomaly 1.5.3 + **точная** MT EXE из таблицы в руководстве. Игровые файлы и сохранение не распространяются.
5. DLL находится в `package/gamedata/plugins/R1_XREAL_Native/R1_XREAL_Native.dll`. Простое копирование туда не загружает её автоматически: тест делает `ffi.load`, затем `r1st_install` и heartbeat `r1st_set`.

Исходники находятся в `native`, тесты — в `tests`, результаты — в `evidence`. Для самостоятельной сборки достаточно исходников, MinHook из `vendor` и Windows SDK/MSVC; Python, старый локальный toolkit и исходники всего движка не требуются. `R1_prepare.py` и `R1_prepare_live.py` — исторические локальные скрипты первоначального эксперимента, с путями автора. Они **не являются переносимым установщиком** и для сборки не нужны.

Откат эксперимента: завершить отдельный тестовый процесс, отключить тестовые скрипты и DLL в его копии игры. EXE восстанавливать не требуется. Если устанавливаете собственный загрузчик через MO2, выключите именно свой мод и перезапустите игру: DLL закреплена в процессе до его завершения.
