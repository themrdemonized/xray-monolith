# R1 Menu API Test 0.1.0

Минимальный тест: два игровых файла, без DLL, моделей, текстур и MCM. Lua включает заморозку уже загруженного одиночного уровня и облёт на реальных часах; XML сохраняет штатную разметку и даёт имя фону, чтобы временно скрыть его. Обычные Modded Exes не содержат этого API: нужен EXE ветки R1_menu_presentation_api.

Установка только в отдельную тестовую среду Anomaly 1.5.3 + R1 Menu Presentation API DX11 x64. Распаковать gamedata. Загрузить отдельный сейв, открыть паузу/главное меню. ESC возвращает в игру. Для явного NPC автоматический внешний runner вызывает r1_menu_api_test.set_subject(id); по умолчанию центр — актёр. Аддон сам не создаёт NPC и не меняет сейвы. Проверенный формат кадра будет указан в отчёте.

Удаление: закрыть тестовую игру, удалить два файла аддона и вернуть исходный EXE. XML ui_mm_main.xml пересекается с аддонами главного меню; это тестовый набор для чистой среды. Штатный UI Anomaly / GSC Game World, Serhiy Vynnychenko и Tronex; разметка и credits сохраняются. R1 Lua — тестовая интеграция, не полный R1 3D Menu.

Проверено агентом 13.10.2026: 34 автоматических проверок в обычной Anomaly 1.5.3, DX11 x64, 1280×720, на скрытом рабочем столе. Два кадра одной заморозки показывают NPC под прозрачным меню с разными ракурсами при неизменных часах мира; третий — повторный вход. Возврат в игру, настройки HUD, сохранение и холодная загрузка прошли. Полная исходная матрица API ранее прошла ещё 45 проверок на том же EXE.
