# R1 PDA Map API

Форк исходников Modded Exes предоставляет авторам аддонов слои рисования, преобразование координат и события ввода на карте КПК. Lua-модуль — `pda_map`, версия API — 1. Интерфейс инструментов, сохранение рисунков, стирание и отмена остаются в аддонах.

[API и подключение](docs/R1_PDA_Map_API_RU.md) · [English guide](docs/R1_PDA_Map_API_EN.md) · [Проверки и ограничения](docs/R1_PDA_Map_Validation.md) · [Неактивный пример](examples/R1_Pda_Map_Example.lua)

Ветки: `R1-pda-map-api` — обычный движок; `R1-pda-map-api-mt` — экспериментальный перенос на MT. Обе x64 DX11 сборки полностью скомпилированы и слинкованы. Обычная сборка прошла рисование на 2D карте КПК, независимость слоёв, владение вводом и восстановление рисунков из Lua-сохранения после перезапуска на Anomaly 1.5.3 + Modded Exes 2026.10.11. Приёмка MT не завершена из-за нативных сбоев при выходе/загрузке. Точные доказательства и ограничения указаны в отчёте. Старому R1 Map Pencil с DLL нужна отдельная адаптация аддона.

Сборка — штатная VS2022 solution upstream. Сохраняются `License.txt`, авторство и документация исходного проекта. Новый код распространяется на условиях существующей лицензии репозитория; сторонние DLL и изображения аддона не включены.
