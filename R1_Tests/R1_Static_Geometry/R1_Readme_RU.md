# Нативные проверки Static Geometry

Сначала соберите DX11 x64 движок с его штатным подмодулем. Затем соберите этот
R1_CDB_Tests.vcxproj в Release|x64 той же версией VS2022/SDK. Исполняемый файл:
`_build/R1_Static_Geometry_Tests/R1_CDB_Tests.exe`.

Ожидается 19 проверок обычной ветки и 10000 конкурентных
запросов при 500 изменениях маски. Используются реальные xrCDB/xrCore и дерево
OPCODE. Проверяются IEEE CRC32, целостный отказ неверных ID, ray/box/frustum,
неизменные снимки, reset/revision и независимая модель.

Консольный host предоставляет только служебные функции логирования/версии.
Он не проверяет Lua VM, рендерер или игровую физику ODE. Для них нужны отдельные
игровые прогоны. Ресурсы игры, EXE и сейвы сюда не включены.
